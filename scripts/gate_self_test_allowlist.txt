# Gate scripts that have no self-test yet (#2248 follow-up).

# A gate that cannot fail is worth nothing, and the only way to know it can
# fail is to make it fail. check_selector_precedence.sh reported ok on a
# hijackable tree FIVE times before it grew one; each defect was found by a
# reviewer, and each red test that proved the fix lived only in a commit
# message, so the guarantee vanished the moment the file changed again.
#

# the gate FAILS. This file is the ratchet for the ones that predate the rule:
