# Heavy KPI cases for cutover ratio measurement.
#
# kpi_cases.txt files are all small (<= 71 LOC), so host check wallclock is
# dominated by CLI cold-start (~1.2s) and the actual typecheck cost is
# invisible — that makes check_ratio look (misleadingly) < 1.0× because
# selfhost via moonrun amortizes startup differently.
#
# These heavier fixtures (1300-2700 LOC each) push enough typecheck work
# per call that host's faster typecheck overcomes its startup cost. The
# resulting check_ratio is the apples-to-apples cutover indicator.
