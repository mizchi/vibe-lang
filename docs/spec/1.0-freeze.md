# vibe 1.0 言語仕様 Freeze

> Status: **accepted** (2026-06-25) — M4 / GA の前提となる「どこまでを 1.0 で
> 凍結し SemVer 保証するか」の決定レコード。`docs/release-roadmap.md` の未決 ADR
> #4 に対応する。細粒度の locked decisions は
> [spec/decisions.md](decisions.md)、全 ADR は [adr.md](../adr.md) を参照。

> **0.3 読み替え (2026-07-17, ADR-0067 / #805)**: GA のバージョン番号は
> 1.0 から **0.3** に renumber された。本ドキュメントの「1.0 タグ」は
> **v0.3.0 GA タグ**と読み替え、freeze は v0.3.0 から発効する。0.x 系の間は
> SemVer 表 (§1) を一段ずらして適用する — stable surface の破壊的変更 =
> **Minor** バンプ (0.3 → 0.4)、後方互換な追加・修正 = **Patch**。1.0.0 に
> 到達した時点で §1 の表が字義どおり (破壊的変更 = Major) に切り替わる。
> 本文の以降の「1.0」は改稿せずこの読み替えで運用する。

このドキュメントは vibe **1.0** で外部ユーザーに対して安定保証する表面
(stable surface) を列挙し、その外側 — 実験的・変更余地ありの領域 — を明示する。
1.0 タグ以降、stable surface への破壊的変更は **Major** バンプを要する。

---

## 1. SemVer 保証ポリシー

vibe は **SemVer 2.0.0** に従う。バージョンは言語そのもの (`vibe version` が
報告する toolchain version) とユーザーパッケージ (`index.vibe` の `version`)
の双方に適用される。

| 変更種別 | バンプ | 例 |
| --- | --- | --- |
| stable surface の破壊的変更 | **Major** | 既存構文の意味変更、prelude シンボル削除、CLI コマンド削除 |
| stable surface への後方互換な追加 | **Minor** | 新構文 sugar、新 prelude シンボル、新 CLI フラグ |
| 振る舞いを変えない修正 | **Patch** | バグ修正、診断メッセージ改善、内部最適化 |

trait bound の互換は [decisions.md](decisions.md) のロック通り
**tighter bounds = Major / looser bounds = Minor**。

**unstable surface (§6)** は 1.0 の SemVer 保証の対象外。これらは Minor の
うちに破壊的変更が入り得る。`@build.unstable` / 明示フラグでのみ到達する
機能、および `proposed` ステータスの ADR が該当する。

## 2. 凍結される言語コア (frozen syntax & semantics)

以下は 0.1.0 sign-off (`docs/archive/report/0-1-0-usability-signoff.md`) で実証済みで、
1.0 で凍結する。各項目の正準定義は [spec/syntax.md](syntax.md) と
[cheatsheet](../cheatsheet.md)。

### 2.1 値と型
- プリミティブ: `Int` (62-bit tagged, 上限 2^61-1, ADR-0006)、`Float` (32-bit)、
  `Double` (64-bit)、`String`、`Char` (Int alias)、`Bool`、`Unit`。
- リテラル: 整数 (10進/`0x` hex)、浮動小数 (`1.5f` / `3.14`)、文字列
  (補間 `\{expr}`; 旧 `\(expr)` は 0.3.0 で削除)、文字 `'A'`、`true`/`false`、`()`。
- 複合型: タプル `(A, B)`、`Array[T]`、`Map[K, V]`、record、struct、enum、
  関数型 `(A) -> B`、エフェクト付き `(A) -> B with E`、ジェネリクス `[T]`、
  trait bound `[T: A + B]`、`Option[T]` sugar `T?` (ADR-0046)。

### 2.2 束縛と可変性
- `let` (immutable)、`let rec` (再帰)、`let mut` (block-scoped 可変, ADR-0017)。
- 分割束縛 `let (a, b) = ...` / `let Some(v) = e else { ... }`。
- 5 つの mutation スタイル (cheatsheet の表)、`struct { mut field }` (ADR-0052)。

### 2.3 関数と呼び出し規約
- ラムダ `(x) -> { ... }`、型注釈分離形 `let f: (T) -> U = (x) -> { ... }`。
- ラベル引数 `f(x=10)` / `x~`。
- ショートハンド `_ * 2` (section)、`_` placeholder。
- **Pipe-first** `x |> f` (ADR-0020)、`_` スロット substitution。
- `.` はフィールドアクセス専用 (メソッド呼び出し sugar なし)。
- 名前解決順: local > lexical > import > prelude。

### 2.4 制御構文
- `if`/`else` (式)、`match` (ガード `if`、or-pattern `A | B`)、`while`、
  `for-in` (Array へ collect、index 形 `for i, x in`)、`loop`/`break(v)`/
  `continue(...)` (ADR-0047)、`return` (早期脱出)。
- パターン: wildcard、binding、literal、constructor、tuple、record、struct、
  or-pattern、guard。
- `is` 式 `expr is Pat` (ADR-0023)。

### 2.5 型定義と trait
- `type` alias、`enum`、`struct`、`derive(Eq)` (ADR-0045)。
- trait: nominal・marker (v0, decisions.md)、supertrait `trait Ord: Eq`、
  `export trait` (sealed) / `export open trait` (extensible)、
  `impl [T: Eq] Eq for Array[T]` (conditional impl)。

### 2.6 エフェクトシステム
- pure-by-default、`with E` 注釈。
- `throw`/`handle ... with Exception { ... }`、`?` operator (ADR-0016, 0050)。
- `suberror` (typed errors)。
- ユーザー定義 algebraic effect `effect`/`perform`/`handle ... with`/`resume`
  (one-shot, lexical-scope, ADR-0050, 0021 Phase 1 tail-resumptive)。
- effect polymorphism `with e`。

### 2.7 モジュールシステム
- `export` / `import ./path { names }` / `as` rename / `type`・`trait` import /
  re-export。
- `module Name { ... }` block、qualified `Type::method` / `Module::name`。
- パッケージ参照 `@json` / `@lib/path`。
- import パスはファイルの root を越えられない (locked)。

## 3. 凍結される標準ライブラリ / prelude 表面

[cheatsheet](../cheatsheet.md) の "Key Builtins" に列挙された安定シンボルを凍結:

- **String**: `length`, `concat`, `substring`, `contains`, `index_of`, `split`,
  `trim`, `replace`, `starts_with`, `ends_with`, `join`, `from_char_code`,
  `char_code_at`, `to_bytes`。
- **Array**: `length`, `get`, `slice`, `map`, `filter`, `fold`, `find`, `any`,
  `all`, `reverse`, `concat`、`ArrayBuilder::new/push/freeze`。
- **Map**: `get`, `has_key`, `keys`, `values`, `set`, `size`。
- **Int64Array**: `make`, `get`, `set`, `length` (32-bit word workload 用)。
- **変換**: `Int::to_string`, `Int::to_double`, `Double::to_int`。
- **Iterator/Iterable** (ADR-0044): `Iterator::map/filter/fold/find/any/all/
  flatmap`、`Iterable` trait、`for-in` desugar。
- **prelude helper**: `compose`/`identity`/`flip` (func)、`tap`/`tap_ok`/
  `tap_err`/`tap_some` (io)、`Result::and_then`、`let*` railway bind。
- **I/O** (effect 必須): `stdout_write` ({Stdout})、`stdin_read_line` ({Stdin})、
  `sh`/`sh_lines` (structured shell)。

> prelude シンボルの**追加**は Minor、**削除/シグネチャ変更**は Major。

## 4. 凍結される CLI / ツール表面

`runtime/vibe` launcher が提供する以下のサブコマンドと契約を凍結する
(テーマ1 install 配布物の一部):

| コマンド | 契約 |
| --- | --- |
| `vibe run <file>` | compile & execute。`--trace` / `--break` はデバッグ用 opt-in。 |
| `vibe compile` / `vibe build [--release] <file>` | standalone `.wasm` 生成。 |
| `vibe check [--single-file] [--json] <file>` | 型検査のみ。located 診断 (`line N:M:`) を **stdout** に1件1行。**clean = 空出力 + exit 0**、診断ありは exit 1。`--single-file` は import を解決しない単一ファイル解析 (未保存バッファ用)、`--json` はそのモードでのみ (#1567)。 |
| `vibe test <file|dir>` | テストブロック実行。 |
| `vibe new` / `vibe add` | プロジェクト初期化 / 依存追加。 |
| `vibe fetch [--frozen]` / `vibe verify` | module 取得・lock 検証 (テーマ2)。 |
| `vibe lsp` | LSP サーバ (テーマ4)。 |
| `vibe type-at` / `vibe binding-at` | エディタ統合プリミティブ。常に exit 0 (照会であって判定ではない)。 |
| `vibe diagnostics` | **deprecated** (#1567): `vibe check --single-file` が後継。既存エディタのために挙動を凍結して残置する — 生の診断行 (`error: ` prefix 無し)、常に exit 0。 |
| `vibe version` | toolchain version 報告。 |
| `vibe self update --cli-wasm <path>` | compiler wasm の入れ替え (runner と独立)。 |

- **配布モデル** (ADR 決定事項 #1): 独自ビルド wasmtime runner + compiler wasm の
  分離配布、install 時 `.cwasm` AOT、compiler は runner と独立更新。
- **module 配布** (ADR 決定事項 #2): git/URL 分散、中央 registry なし、
  content hash で lock (`index.lock`)、semver 制約解決 (`^`/`~`/`>=`/`x`/`*`)。
- ファイル規約: `*.vibe` / `index.vibe` (exports `version`) / `index.lock` /
  `*_test.vibe`。

## 5. 凍結されるフォーマット / 正準化

[decisions.md](decisions.md) のロック通り:
- enum variant separator は `;` に正準化。
- struct literal は `Type::{ ... }` スタイル。
- formatter (`vibe fmt`) は idempotent。
- 型命名: ユーザー型は CamelCase、wasm builtin primitive (`i32`/`f32`/`f64`) は
  lowercase 予約。

## 6. 1.0 で凍結しない領域 (unstable surface)

以下は実装途上・設計確定前で、1.0 の SemVer 保証の**対象外**。Minor の
うちに破壊的変更が入り得る。利用する場合はこの不安定性を承知すること。

- **Async / 構造化並行 / WASI 0.3** (ADR-0012/0068, `proposed`): `{Async}`
  effect、`Future[T]`、`Stream[T]`、`Task[T]`、`for await`。現行 codegen は
  eager prototype で、v0.4.0 の公開意味論は
  [structured concurrency spec](../concurrency.md) に定義する。JSPI / Worker、
  WASI Component Model、shared-everything は交換可能な lowering であり、
  いずれか一つへ stable surface を結び付けない。
- **Component Model `#import` 統合** (ADR-0021 Phase 2/3): non-tail-resumptive
  handler の CPS lowering、capability effect。
- **Capability-driven DCE / `--profile` プリセット** (ADR-0043, `proposed`)。
- **`_start` capability 宣言と top-level effect 規則** (ADR-0041/0042,
  `proposed`)。
- **SIMD API** (`spec/simd-api-design.md`)。
- **デバッガの行粒度 step / call-site hover** (span-arc): 関数粒度 step・型付き
  hover は安定 (テーマ3/4 着地済み) だが、行粒度 step と任意式 watch は将来拡張。
- **LSP の incremental 解析** (roadmap 4-4, 任意)。
- **wasm-gc backend の HOF/Iterator codegen ギャップ** (`VIBE_*_BACKEND=gc`):
  既定 linear backend が安定面。gc は opt-in の実験面。

---

## 7. Freeze の運用

- 1.0 タグ後、stable surface (§2–§5) への変更提案は ADR で Major 影響を明記する。
- unstable surface (§6) が安定化したら、本ドキュメントの §2–§5 へ移し対応 ADR を
  `accepted` に更新する (= 次 Minor で stable 入り)。
- `vibe version` が報告する toolchain version が SemVer の基準。
- このドキュメント自体の改訂は ADR ログ (adr.md「Release / GA」節) で追跡する。
